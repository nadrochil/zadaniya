# Задания — доска карточек с задачами

Сайт для команды: карточки с работой на канбан-доске (Не начато / В работе /
Готово), внутри каждой — список пунктов с подпунктами, приоритет, срок,
ответственный, теги, фото, комментарии и история изменений. Вместо
регистрации — просто ввод имени, оно запоминается и видно рядом с правками.

Это **один файл** — `index.html`. Общая доска для всей команды уже работает
по ссылке **https://nadrochil.github.io/zadaniya/** — никакого аккаунта
Claude и никакой установки не требуется, достаточно открыть ссылку в
браузере.

## Возможности

- Канбан-доска: карточки перетаскиваются между колонками (или кнопками ‹ ›
  на самой карточке) — статус «Не начато» / «В работе» / «Готово»
- Пункты и подпункты внутри карточки, можно добавлять, редактировать,
  отмечать выполненными, удалять
- Полноэкранный просмотр карточки — клик по значку ⤢
- Приоритет, ответственный, срок выполнения (с подсветкой просроченных),
  повторяющиеся задания (кнопка «Повторить» сбрасывает пункты и, если задан
  срок, сдвигает его на следующий период)
- Теги и поиск/фильтры («Мои», «Просрочено», «Не завершено»)
- Архив карточек
- Комментарии и фото на карточке, история изменений
- Шаблоны: сохранить карточку как шаблон и быстро создавать новые из неё
- Статистика по доске и экспорт в CSV

## Как это работает

Общее хранилище — бесплатная база **Firebase Firestore** (проект
`zadaniya-87f0b`), подключённая прямо в `index.html`. Открыв
**https://nadrochil.github.io/zadaniya/**, любой человек из команды видит
одну и ту же доску, и все правки — новые карточки, отметки пунктов,
перемещения между колонками — появляются у всех в реальном времени.
Аккаунт Claude или Google для этого не нужен, регистрация не нужна —
только ввод имени, чтобы было видно, кто что изменил.

Если открыть `index.html` без интернета (или Firebase окажется
недоступен), сайт автоматически переключается в автономный режим:
карточки и шаблоны сохраняются только в этом браузере
(`localStorage`) и не синхронизируются с командой, пока соединение не
восстановится и страница не будет перезагружена. Это подстраховка, а
не основной режим работы.

## Как открыть локально

Просто откройте `index.html` в браузере — он подключится к той же общей
базе Firebase, что и https://nadrochil.github.io/zadaniya/.

## Как выложить на GitHub

```bash
git init
git add index.html README.md
git commit -m "Задания: доска карточек с задачами"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/<название-репозитория>.git
git push -u origin main
```

Если хотите ещё и открыть сайт по ссылке через **GitHub Pages**: в репозитории
откройте Settings → Pages → Source → выберите ветку `main` и папку `/root` →
Save. Через пару минут сайт появится по адресу вида
`https://<ваш-логин>.github.io/<название-репозитория>/`.

Учтите: `index.html` подключается к конкретному проекту Firebase
(`zadaniya-87f0b`, конфигурация — в начале `<script>` в файле). Если вы
форкаете репозиторий для отдельной, независимой доски — заведите свой
проект на https://console.firebase.google.com, создайте в нём базу
Cloud Firestore и подставьте свой `firebaseConfig` вместо текущего, иначе
новая копия сайта будет писать в ту же базу, что и оригинал.

## Технические ограничения (заложены сознательно)

- Фото сжимаются на устройстве до ≤480px и среднего качества JPEG, максимум
  3 на карточку — иначе карточка не влезает в лимит общего хранилища
- История изменений хранит последние 30 записей на карточку, комментариев —
  последние 200
- Повтор задания («Повторить») запускается вручную кнопкой, а не по таймеру
  автоматически
- Правила доступа Firestore открыты на чтение/запись без входа в аккаунт
  (иначе команда без Google/Claude-аккаунтов не смогла бы пользоваться
  доской) — но только для трёх коллекций, которые использует само
  приложение (`cards`, `members`, `templates`). Это осознанный компромисс
  для небольшого внутреннего инструмента: ссылку на доску не стоит
  выкладывать в открытый доступ вне команды
