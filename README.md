# Задания — доска карточек с задачами

Сайт для команды: карточки с работой на канбан-доске (Не начато / В работе /
Готово), внутри каждой — список пунктов с подпунктами, приоритет, срок,
ответственный, теги, фото, комментарии и история изменений. Вместо
регистрации — просто ввод имени, оно запоминается и видно рядом с правками.

Это **один файл** — `index.html`. Открывается двойным кликом в браузере,
никакого сервера или установки не требуется.

## Возможности

- Канбан-доска: карточки перетаскиваются между колонками (или кнопками ‹ ›
  на самой карточке) — статус «Не начато» / «В работе» / «Готово»
- Пункты и подпункты внутри карточки, можно добавлять, редактировать,
  отмечать выполненными, удалять
- Полноэкранный просмотр карточки — клик по значку ⤢
- Приоритет, ответственный, срок выполнения (с подсветкой просроченных),
  повторяющиеся задания (кнопка «Повторить» сбрасывает пункты и, если задан
  срок, сдвигает его на следующий период)
- Теги и поиск/фильтры («Мои», «Просрочено», «Не завершено»)
- Архив карточек
- Комментарии и фото на карточке, история изменений
- Шаблоны: сохранить карточку как шаблон и быстро создавать новые из неё
- Статистика по доске и экспорт в CSV (только по живой ссылке от Claude,
  см. ниже)

## Два режима работы

Этот файл — резервная копия кода. У него два режима, и он сам определяет,
какой использовать:

1. **Живая ссылка от Claude** (её вам уже прислали в чате) — там подключено
   настоящее общее хранилище: карточки, правки и имена участников сохраняются
   на сервере и видны всей команде в реальном времени. Только там же работает
   экспорт в CSV и сохраняются фото между устройствами.
2. **Этот файл сам по себе** (открыт локально или размещён на GitHub Pages) —
   общего хранилища у него нет, потому что оно работает только внутри Claude.
   Поэтому сайт автоматически переключается в автономный режим: карточки,
   шаблоны и фото сохраняются в браузере (`localStorage`) и никуда не
   пропадают при перезагрузке страницы, но видны только на этом устройстве,
   в этом браузере — не всей команде. Кнопка «Экспорт CSV» в этом режиме
   покажет сообщение, что экспорт доступен только по ссылке от Claude.

Иначе говоря: **для совместной работы команды пользуйтесь ссылкой от Claude**,
а этот репозиторий — это исходный код на случай, если он понадобится отдельно
(посмотреть, доработать, разместить как одиночный инструмент для себя).

> Если позже понадобится именно совместный сайт со своим сервером и базой
> данных (чтобы не зависеть от ссылки Claude), это отдельная задача — дайте
> знать, соберём.

## Как открыть локально

Просто откройте `index.html` в браузере. Всё будет работать в автономном
режиме (см. выше).

## Как обновить репозиторий с компьютера

```bash
git clone https://github.com/nadrochil/zadaniya.git
cd zadaniya
# внесите изменения в index.html
git add index.html README.md
git commit -m "Обновление"
git push
```

Если хотите ещё и открыть сайт по ссылке через **GitHub Pages** (в автономном
режиме, без общей базы — см. предупреждение выше): в репозитории откройте
Settings → Pages → Source → выберите ветку `main` и папку `/root` → Save.
Через пару минут сайт появится по адресу
`https://nadrochil.github.io/zadaniya/`.

## Технические ограничения (заложены сознательно)

- Фото сжимаются на устройстве до ≤480px и среднего качества JPEG, максимум
  3 на карточку — иначе карточка не влезает в лимит общего хранилища
- История изменений хранит последние 30 записей на карточку, комментариев —
  последние 200
- Повтор задания («Повторить») запускается вручную кнопкой, а не по таймеру
  автоматически
